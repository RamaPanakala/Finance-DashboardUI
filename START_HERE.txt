FOR DEVELOPERS:
═════════════════════════════════════════════════════════════════════════

  Import utilities:
  ─────────────────
  import { convertCurrency, formatCurrency } from '../utils/currencyUtils';
  
  Get from context:
  ──────────────────
  const { currency, exchangeRates } = useAppContext();
  
  Create helper:
  ──────────────
  const formatAmount = (amount) => {
    const converted = convertCurrency(amount, 'USD', currency, exchangeRates);
    return formatCurrency(converted, currency, getLocaleForCurrency(currency));
  };
  
  Use in JSX:
  ───────────
  <div>{formatAmount(totalBalance)}</div>

🔄 DATA FLOW
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

User clicks currency selector
           ↓
CurrencySelector component opens
           ↓
User selects new currency (e.g., EUR)
           ↓
setCurrency('EUR') called
           ↓
AppContext.currency updated
           ↓
localStorage saves preference
           ↓
All components re-render
           ↓
Each component calls formatAmount(usdValue)
           ↓
convertCurrency() converts USD → EUR
           ↓
formatCurrency() applies EUR formatting
           ↓
User sees amounts in EUR with € symbol ✅
